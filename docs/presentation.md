# Taipei Run：60 秒舞台講法

目標是先讓評審看到一個能玩的畫面，再講清楚真人體感、遊戲笑點與可帶走的美食護照。開場直接播放，邊播邊講，不在第一秒停下解釋設定。

## 一分鐘的講法與時間切點

下列是**配合事先錄好的 60 秒加速影片的舞台講話安排**，不是已量測的最終影片逐幀時間。一般遊戲約 75 秒；真人互動另做現場短示範。現有錄影以 1.42 倍播放含倒數的約 78 秒流程，約 55 秒到結尾，再保留結尾展示時間（`src/game/engine.ts` 的 `record()`）。預先排練後按實際畫面微調句子，不能為了趕講稿跳過真人辨識確認。

| 舞台時間 | 畫面／操作 | 建議講法 |
| --- | --- | --- |
| 0–3 秒 | 直接播影片，星空地球旋轉並拉近台灣；倒數後切夜市 | 「如果台灣人的日常變成體感跑酷，會怎樣？」 |
| 3–12 秒 | 跑者自動前進與左右移動；右下本人鏡像畫面在真人場才展示 | 「真人玩的時候，你站在原地，身體往哪邊，角色就往哪邊。路面自己往後跑。」 |
| 12–24 秒 | 吃食物、金幣 DING；示範 Jump、Duck，教練追 | 「一邊運動，一邊把小吃吃回來。你真的跳，角色大叫；你蹲，他就滑過去。」 |
| 24–38 秒 | 垃圾車進場；看到 THROW 才揮手；垃圾丟進車 | 「這一關不是打怪，是追垃圾車。手一丟，台灣人的日常就變成任務。」 |
| 38–49 秒 | YouBike 必殺技爆發、上方標示、速度線、加速 | 「YouBike 一開，直接爆衝，連教練都甩掉。」 |
| 49–55 秒 | 巨大珍奶與教練追回，總分結尾 | 「結果還是為了珍奶被教練抓到。現在才正式開始運動。」 |
| 55–60 秒 | 切回網頁結尾，開「我的台灣美食清單 / YOUR FOOD TRAIL」；不要假稱 DOM 清單已錄進 canvas 影片 | 「剛才真的吃到哪些小吃，會變成你的美食護照；中英名稱、數量、Maps 搜尋，還能下載帶走。」 |

若用正常 75 秒真人遊戲，事件時間會比這個講法更晚，請繼續讓遊戲跑完，不要假稱一分鐘內完成整趟。舞台時間被硬性限制 60 秒時，用清楚標示的自動加速影片展示完整流程，再另外展示已排練的真人左右、跳、蹲操作。

## 現場與影片各證明什麼

- **真人現場：** 真正開 Camera、完成全身校準，透過本人移動控制角色；右下畫面與骨架讓旁觀者看懂。先測光線、距離與全身是否入鏡。
- **60 秒內建影片：** 固定事件的加速自動演出，標「自動演出 · 非體感示範」。它證明畫面／事件／聲音的呈現，不證明真人辨識成功。
- **真人錄影：** 若要提交體感證據，實際操作並錄到本人畫面與遊戲同步；不要把 Camera 開著的自動演出改標為真人。
- **美食護照：** 收集數量來自這一趟實際碰到的食物；Google Maps 是食物搜尋外連，不會建立玩家帳號裡的 Saved List，也不是餐廳推薦排序。
- **美術概念：** `/styles.html` 的九張圖片用來選風格，不是九套已完成的動畫與 3D 遊戲。
- **地球開場：** 程式即時生成 3D 球體、星空與簡化地圖；台灣高亮是示意，沒有宣稱測繪精度。

## 最後兩分鐘驗收

時間不足時照下列順序，不再加功能。

| 時間 | 當場確認 | 通過的可觀察結果 |
| --- | --- | --- |
| 0–20 秒 | 開場、聲音、畫面 | 三秒內切夜市；倒數／哨聲可聽；不是空白 canvas |
| 20–55 秒 | 真人左右、跳、蹲與右下視訊 | 左右各三次方向一致；跳一次只觸發一次；蹲兩秒不提前站起；本人畫面持續可見 |
| 55–75 秒 | 追蹤失去與 Throw 備援 | 出畫面有提示且解除蹲；回來不憑空 Jump／Throw；鍵盤 `F` 可接手事件 |
| 75–100 秒 | 重播已錄好的影片、檢查結尾 | 檔案可播放，有動作聲；垃圾車、YouBike、結尾存在；自動／真人標示正確。這段需事先已錄好，不是假稱25秒看完60秒影片 |
| 100–120 秒 | 美食護照與交付網址 | 數量與這趟結果一致；一個 Maps 搜尋可開；下載 HTML 可重開；GitHub 與遊戲／風格入口可給評審 |

WebAudio 動作音會錄進內建影片；中文教練 `speechSynthesis` 與真人麥克風目前不在這條音軌，必須靠字幕或另錄聲音。Camera 預覽能否進錄影，以下載檔為準。

本文提供排練安排與驗收條件，沒有宣稱所有現場動作、店家內容、部署或60秒成片已親自驗證。
